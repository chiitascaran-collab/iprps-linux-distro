# IPRPS OS Session Master Training Manual

A training guide for Session Masters using IPRPS OS, at an 8th-grade reading level, with seven step-by-step walkthroughs. It covers what makes IPRPS OS different from online tabletops such as Roll20, Owlbear Rodeo, Alchemy RPG, Fantasy Grounds and D&D Beyond; setting up a campaign; preparing a session; the IPRPS Table; IPRPS rolls and bands; the Combat Tracker; the Soundboard; the IPRPS Oracle; the Session Log and recap; updates; and remote players.

**Publish the website:** upload this whole folder to the web server (for example to `infiniteplane.space/iprps-os/manual/`). `index.html` is the page; its **Download PDF** and **Download Word** buttons use the two files in this folder. Nothing else is needed: no server code, no outside fonts or scripts.
