# Roadmap

These are plans, not promises; release notes say what actually shipped.

**Shipped in 1.0 (Beta):** Lite, Medium and Advanced editions; IPRPS Desktop; Session Master Mode and Hub; campaign database; IPRPS Table (LAN play); IPRPS Oracle (local AI, Medium and Advanced); the package manager and IPRPS Updates; first-boot setup, installer and live ISO. Since then through updates: Master Database, Character Prompt Builder, and the optional IPRPS Link (remote players) and IPRPS Podcast Studio.

1. **1.0 final** — the 32 server web apps overhauled; IPRPS Link and Podcast Studio tested on real hardware and the internet.
2. **New apps, first as updates, then in 1.1 for Medium and Advanced** — an **IPRPS CD/DVD player**, and the **AI Session Master** as its own app (with access to AI profiles, patches and capstones).
3. **IPRPS Oracle** — a custom IPRPS model, fine-tuned as an RPG storyteller, installable next to the bundled Llama 3.2 3B.
4. **1.1** — persistent live USB (keep changes on the stick) and a graphical installer.
5. **Remote play service** — a hosted relay with Infinite Plane accounts, so Session Masters don't need their own (on hold).
