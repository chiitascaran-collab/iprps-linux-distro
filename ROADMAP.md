# Roadmap

These are plans, not promises; release notes say what actually shipped.

1. **1.0** — Lite, Medium and Advanced editions; IPRPS Desktop; Session Master Mode; campaign database; first-boot setup and installer.
2. **1.1** — Live ISO: try IPRPS read-only from USB or DVD, install from there.
3. **IPRPS apps** — Session Master Hub (campaigns, players, initiative, dice, session log, player display), Soundboard, IPRPS File Viewer (`.iprps`, `.ipai`, `.srpatch`, `.capstone`), IPRPS Welcome (first-run tour, API key vault).
4. **Local AI assistant** — NPC dialogue, encounter ideas and recaps, fully offline, Advanced edition first (16 GB RAM minimum; models downloaded on demand).
5. **Package manager** — in-place updates and security fixes without reinstalling.
