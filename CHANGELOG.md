# Changelog

## 2026-10-28

- **IPRPS Table (12.7), all editions:** LAN play for computers with one screen. Any phone, tablet, laptop or desktop on the same network joins the Session Master's campaign at `http://<computer>:7777/` with a join code (or a QR code). Players: chat to everyone, players only, privately to the Session Master or to another player, with images (paste works) and audio files; a dice toolbar with the IPRPS rolls (skill check with bands and BTN, initiative, reaction, Trinity/Hydra Hand, Dual-Die, Infinite Convergence with exploding dice, RPS, weapon damage) and visibility per roll. Session Master console (this computer only): who is at the table (online, device, address, last seen), groups, messages to everyone/groups/selected/one player, push images, video and text cards, play sound (looping) on players' devices, secret rolls, copy buttons, kick, lock, new code. Node.js core only, its own system account and hardened systemd unit (`iprps-table.service`), rolls made on the server, files visible only to their recipients. Session Master Mode opens it instead of a player display window on one-screen computers; it's a Hub default app. Release cleanup empties its data.
- Hub default apps now list **IPRPS Table** after Writer.
- **Before Stage H (Part 15):** snapshot, a free-space check with steps to grow the build image by 40 GB (Medium's LibreOffice build alone needs about 15 GB), memory advice, and a procedure for re-releasing **Lite** with fixes made during Stage H: `iprps-enter.sh`, `iprps-leave.sh` and `iprps-release-clean.sh` now take `IPRPS_IMG=<image>` to work on a Lite fix copy.
- wpa_supplicant section: checks for the Wi-Fi drivers (`nl80211`, `wext`) and libnl before installing.

## 2026-10-26

- **First-boot setup (13.2)** rebuilt as menu screens: a welcome that describes IPRPS OS, the three editions (showing the installed one), hardware and other limits, then account, full name, password (twice, 8+ characters), computer name and a **time-zone menu** (common US/Canadian zones, or region and city); a summary to confirm or change. `IPRPS_SETUP_DRYRUN=1` previews it.
- **Apache/PHP (10.1):** BLFS's `ProxyPassMatch` sent every `.php` address to PHP-FPM unchecked, so apps whose start page is `index.html` (the Hub, Writer, the Oracle) showed "File not found."; replaced by a `FilesMatch` handler in `/etc/httpd/extra/iprps-php.conf` (tested with Apache 2.4 and PHP-FPM), which also streams the Oracle's replies, so the Oracle's own Apache step is gone.
- **Fixes from the second real-hardware test:** wpa_supplicant's D-Bus build option and D-Bus files are now marked **required** (BLFS calls them optional; without them NetworkManager can't use Wi-Fi: the menu was greyed out). 10.2 creates `/usr/share/iprps/schema` before saving the schema (first boot failed with "iprps-core.sql: No such file"). Apache, PHP-FPM and MariaDB unit installs are marked required. New Firefox policy file: no telemetry, studies or first-run pages, the Hub as home page (faster offline start).
- **IPRPS Writer (12.6):** a simple word processor in the Hub and menu (`apps/writer/`), on by default: headings, bold/italic/underline, lists, alignment, word count, autosave per account; imports and exports `.docx` and `.odt` (round-trip tested), `.txt`, `.html`, and PDF through printing. No libraries; its own ZIP and DOCX/ODT writers.
- **Drawing (Part 11, Lite):** a simple painting program (Drawing 1.0.2, GPL-3.0, Python/GTK 3), built with Meson from what Lite already has.
- **Session Master Hub (12.6):** the Hub's home page (`apps/hub/`): the Session Master's apps as tiles, and **Manage apps**, listing every app in `/srv/www/iprps` with an on/off switch, saved per account. Default apps: Prompt Database, Expressions, SFX, Character Development, IPRPS Writers Studio, Camera Patch Generator, Reel, Language, Lighting Generator, IPRPS Email (`default-apps.json`). Includes the player display page (`display.php`), so Session Master Mode is complete in Lite.
- **Wi-Fi Networks window (9.9):** `iprps-wifi` scans and lists networks (signal, security, connected), connects with a password prompt, joins hidden networks, and opens NetworkManager's advanced editor **for the selected network** with its name and security already set. The menu's Advanced Network Configuration entry (renamed **Wi-Fi and Network Connections**) opens it.
- **Boot messages:** release images leave `/etc/machine-id` **empty** instead of `uninitialized`, which made systemd treat the first boot as a reset-all-services ("Failed to preset all unit" lines; had it succeeded, it would have disabled IPRPS's services). Broken service links are removed at release; the conflicting PC-speaker drivers are blacklisted.
- **First real-hardware test fixes:** `iprps-db-init` waits up to 3 minutes for MariaDB (its first start on a slow USB stick outran it: "database could not be created"); a **polkit rule** makes `wheel` members the administrators (prompts asked for the locked root password, so saving Wi-Fi failed) and lets the person at the computer save Wi-Fi without a prompt; **Session Master Mode** opens the player display full screen only with a second screen, and only when a display page exists (a white full-screen page trapped single-screen users).
- **Initramfs fixes (4.9):** no longer copies the whole firmware collection (it was over 1 GB, slow to load from USB); it now includes the USB core (`usbcore`, `usb-common`; BLFS's mkinitramfs left them out, so real PCs had no USB at boot), loads USB keyboard drivers (`usbhid`, `hid_generic`) and waits up to 30 seconds for the root device; real PCs booting from a USB stick stopped at "/dev/disk/by-uuid/... does not exist" because the stick appears a few seconds after its drivers load. `initramfs/iprps-usb-wait.sh`.
- **Release scripts (13.4, 13.5):** `build-host/iprps-release-clean.sh <edition>` (copy, empty databases, retire the test password, app-data review, general cleanup, edition name, safe unmount; undoes its mounts on any error) and `build-host/iprps-release-pack.sh <edition>` (shrink, health check, `.img.xz`/`.vhdx`/`.qcow2`, checksums, verified copy to `G:\IPRPS\release`). No more `<edition>` placeholders to replace. The partition table is now rewritten after shrinking (keeping all IDs), which is more reliable than relocating the backup GPT.
- **Release fixes (13.4–13.6):** `mount --make-rslave` and a step-by-step unmount (no more "target is busy"), `/etc/iprps/db.php` removed from release copies, edition placeholders explained, a partition wait before the health check, and QEMU overlay tests (full backing path) plus USB-on-a-real-PC notes (BitLocker) for builders without Hyper-V.

## 2026-10-25

- **Local AI (Medium and Advanced, Part 15):** **Ollama** as a local-only service (Vulkan for AMD/Intel GPUs, NVIDIA libraries removed) with the bundled **iprps-storyteller** model (Qwen3.5 4B, Apache-2.0, plus the IPRPS Modelfile), and the new **IPRPS Oracle** app (`apps/oracle/`): Session Master chat, seven quick generators, campaign memory from the core database with pinned facts, save to NPCs/quests/session log, and **Show players** on the player display. `iprps-ai-model` installs a custom-trained IPRPS model later without changing the app.
- Session Master Mode preloads the AI model and uses the Oracle's player display until the Hub's own exists. Release cleanup (13.4) now also empties the IPRPS core database and removes Ollama's identity key.
- **Chromium (Medium and Advanced, Part 15):** prebuilt **ungoogled-chromium** in `/opt/chromium` (checked by SHA-256, setuid sandbox helper), a `chromium` command with `/etc/iprps/chromium-flags.conf`, a menu entry, the **default web browser** (`/etc/xdg/mimeapps.list`, Xfce helpers), and managed IPRPS policies: Hub home page, DuckDuckGo, no metrics or promotions, an **IPRPS bookmarks folder** built from the installed apps. Lite keeps Firefox only.
- **`iprps-open` (12.2)** opens each IPRPS app **in its own window** (Chromium app mode) where Chromium is installed, falling back to a Firefox window in Lite; one shared profile, so one Universal Login covers every app.
- **Web apps (Part 12):** 32 apps from the live server plus the Universal Login, installed through `tools/iprps-clean-apps.py` (removes API keys and hosting passwords, maps 16 server databases to local `iprps_*` databases, one local user `iprps`, password placeholder `@IPRPS_DB_PASS@`). Guide 12.5 rewritten with the full procedure, database map and checks.
- **`iprps-db-init` (13.1)** now grants `iprps_*`, fills the placeholder in every app and writes `/etc/iprps/db.php`. **13.4** restores the placeholder, empties every app table and retires the test password before the general cleanup.
- Troubleshooting: MariaDB start-up wait, `iprps` access denied, login-only pages, unreachable app databases.
