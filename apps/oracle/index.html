    🌐 Online: your message, the campaign memory and any named character sheets go to Anthropic to answer. Your Anthropic account is charged for each reply.

    Online AI: Claude

    The Oracle can use Claude, Anthropic's AI, instead of the model on this computer. Claude is usually faster and writes richer NPCs and scenes. It needs internet and your own Anthropic API key. Anthropic charges your account for each reply, and the local model stays free and private.

    What is sent to Anthropic: your message, recent Oracle chat, the campaign memory (when Use campaign memory is on) and the character sheets you name. Get a key at console.anthropic.com → API keys.
