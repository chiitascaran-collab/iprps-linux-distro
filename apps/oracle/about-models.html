On this computer: Llama 3.2 3B Instruct

Built with Llama. The Oracle's local model, iprps-storyteller, is Meta's Llama 3.2 3B Instruct (8-bit, Q8_0) with the IPRPS Oracle's instructions. It runs entirely on this computer through Ollama: no internet, no account and no fees.

The full license is on this computer in /usr/share/iprps/ai/LICENSE-llama3.2.txt, and online at llama.com/llama3_2/license. Using Llama 3.2 means agreeing to Meta's Acceptable Use Policy.

Online (optional): Claude by Anthropic

With your own Anthropic API key, the Oracle can use Claude models instead (Haiku, Sonnet, Opus and Fable). Claude needs internet; your message, recent Oracle chat, the campaign memory and any named character sheets are sent to Anthropic to write each reply, and Anthropic charges your account. Your use of Claude is under your agreement with Anthropic (see anthropic.com/legal).

Changing models

Choose any installed model in the Oracle's Model menu. To switch the local model, use sudo iprps-ai-model in a terminal (status, upgrade, reset).
