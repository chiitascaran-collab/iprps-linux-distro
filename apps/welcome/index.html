Welcome, Session Master.

IPRPS OS is a computer made for running Infinite Plane Role Playing System campaigns: everything for the table in one place, most of it working without the internet.

This short tour shows where things are and sets up a few things for you. It takes about five minutes, and you can skip any step. Open it again any time from the menu: IPRPS → IPRPS Welcome.

On this computer

    Your campaign

    Campaigns hold everything else: sessions, the session log, encounters, character sheets, NPCs and quests. The Oracle (in Medium and Advanced) reads them too.

    Campaigns

      You can add more and edit them from any session tool (the ✎ next to the campaign).

      Your tools

      Everything opens from the Session Master Hub and from the menu's IPRPS section. Session Master Mode (on the panel) opens the Hub, the ambience and the players' screen together.

      Color scheme

      Choose how the IPRPS session tools look (Combat, Dice, Soundboard, Session Log, File Viewer and this tour). It's saved with your account.

      API keys for online AI apps

      Some IPRPS apps use online AI services (the Genesis Character Engine, the Writing Assistant, image generators). They need your own API key from each service: IPRPS OS never ships with keys. Keep yours here, in one place.

      • Keys are stored encrypted on this computer, for your account only. Other accounts can't see them.
      • They never leave this computer. The apps that need a key ask for it while you're signed in.
      • Only the last characters are shown here. Delete a key here, and at the service's website if it may have leaked.
      • The offline tools (Combat, Dice, Session Log, Character Sheets, the Table, the Oracle) need no keys at all.

        You're ready.

        Open the Session Master Hub to start. A good first evening:

        1. Players fill in their sheets in the Character Creator (or on their phones through the IPRPS Table), and you import them in Character Sheets.
        2. Start the session in the Session Log (+ Session).
        3. Roll with the Dice Roller, fight with the Combat Tracker: both write into the session log.
        4. Afterwards, write the recap in the Session Log and show it to the players next time.
